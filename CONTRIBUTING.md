# Contributing

Thanks for helping improve Horse Video. This is a small Remotion experiment, so focused fixes and visual experiments are welcome.

1. Create a branch for your change.
2. Keep source and media changes scoped to the intended composition.
3. Run `npm run typecheck` and, when practical, `npm run render`.
4. Describe the visual or rendering impact in your pull request.

Please do not commit `node_modules`, caches, secrets, or temporary exports. For large media, discuss the approach before adding it.
